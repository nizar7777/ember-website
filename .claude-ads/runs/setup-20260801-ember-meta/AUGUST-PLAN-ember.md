Two tiers, because the honest answer depends on how much risk you want:

**Tier A — break-even, ~$118 total.** Hits the number exactly if August performs
like April–June. Requires running waves at ~$3.50/day, which is below the $5/day
that actually worked. Under-delivery risk.

**Tier B — recommended, ~$140 total (~100 JOD).** Keeps every wave at $5/day,
the rate with a proven track record. Costs ~16 JOD more than break-even demands,
and buys a much better chance of actually getting there.

I'd take Tier B. Starving a wave to hit a spreadsheet number is how you get
July's under-delivery at a higher cost per result.

## The measurement that makes this worth doing

Right now you cannot tell which theme sells shirts. Meta counts conversations;
your sheet counts shirts; nothing connects them.

Add one row per wave to your master sheet:

| Wave | Theme | Dates | Ad spend | Conversations | **Shirts sold** | JOD per shirt |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | current | Aug 1–10 | | | | |
| 2 | anime | Aug 11–17 | | | | |
| 3 | gym | Aug 18–24 | | | | |
| 4 | streetwear | Aug 25–31 | | | | |

Fill "shirts sold" from your order emails, dated within the wave. By 31 August
you will know which of your three themes actually sells — the single most
valuable thing this month can teach you.

Conversations are not the goal. March proved that: ~8,600 conversations, 11
shirts. Judge every wave on the shirts column.

## Assumptions, stated plainly

- Ads scale roughly linearly at these small budgets. July shows they don't always.
- Ads drive most sales. You also get organic and repeat orders, which this
  ignores, so the true ad requirement may be lower.
- 1.75 JOD per shirt is an Apr–Jun average, not a guarantee. August is a quieter
  month in Jordan than May.
- Break-even of 48 shirts is yours, taken from the master sheet, and does not
  account for the extra marketing spend in Tier B.
